รูปแบบการหมุน

ให้สามารถตั้งค่ารูปแบบการหมุนได้ 2 แบบ

Auto Stop
เมื่อกด “เริ่มหมุน” วงล้อจะหมุนตามระยะเวลาที่กำหนด และค่อย ๆ ชะลอความเร็วก่อนหยุดอัตโนมัติที่รางวัล

Manual Stop
เมื่อกด “เริ่มหมุน” วงล้อจะหมุนต่อเนื่องจนกว่าผู้ใช้งานจะกด “หยุด” จากนั้นวงล้อจะค่อย ๆ ชะลอและหยุดที่ผลรางวัล

Animation

การหมุนต้องมี Animation ที่ลื่นไหล โดยแบ่งเป็น 3 ช่วง

Acceleration — วงล้อเริ่มหมุนและเพิ่มความเร็ว

Constant Speed — หมุนด้วยความเร็วคงที่

Deceleration — ค่อย ๆ ลดความเร็วก่อนหยุด

ไม่ควรหยุดวงล้อแบบทันที เพื่อให้ประสบการณ์การเล่นดูเป็นธรรมชาติและน่าตื่นเต้น

Random Logic

ผลรางวัลต้องถูกกำหนดจากระบบ Random อย่างเป็นธรรม และ Animation ของวงล้อต้องหมุนไปหยุดตรงกับรางวัลที่ระบบสุ่มได้จริง

ระยะเวลาหมุนหรือความเร็วในการหมุนต้องไม่มีผลต่อโอกาสในการได้รับรางวัล

กรณีเปิดใช้งาน Weighted Random ให้ระบบคำนวณผลตาม Weight/Probability ที่กำหนดไว้ก่อน จากนั้น Animation จึงหมุนไปหยุดตรงตำแหน่งของรางวัลนั้น

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
